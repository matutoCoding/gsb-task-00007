# 板材开料排版

无依赖的静态开料排版页面，直接用浏览器打开 `index.html`，或在当前目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 功能

- 自动排版，提供“整板集中”和“优先余料”两版策略，可继续手工拖拽调整。
- 实时标出超界、重叠、错误旋转、跨颜色批次混用和锯缝不足。
- 按纹路和颜色批次分组：顺纹/横纹默认不旋转，不限纹路可旋转 90°。
- 每张板计算利用率、已用面积和可留存余料；余料可入库，供后续订单优先提示。
- 修改板件或板材尺寸后，所有方案的未锁定板自动重排。
- 已锁定板材不会被后续自动排版、尺寸变更或拖放冲掉。
- 两版方案并列比较用板面积、平均利用率、待排数量和余料面积。
- 导出 CSV 开料单，包含方案、板件、批次、封边、板材、X/Y 坐标和旋转角度。

## 文件

- `index.html`：页面结构。
- `styles.css`：画板、列表、状态和打印样式。
- `app.js`：数据、拖拽、排料、校验、余料、方案对比和 CSV 导出。

数据保存在浏览器 `localStorage`，不上传服务器；点击“重置样例”可恢复内置演示订单。
